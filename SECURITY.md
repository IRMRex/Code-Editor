# Security Policy
The security of this application is the most important goal. **Full source code is available (via email) upon request.**
Listed below are the versions that are supported for security updates.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x  | :white_check_mark: |


## Reporting a Vulnerability

You can report a security vulnerability as an issue on GitHub, through the private security reporting on GitHub and using the email where you received the source code if applicable.

An update regarding a security vulnerability maybe be expected within the following two weeks after it is reported.
